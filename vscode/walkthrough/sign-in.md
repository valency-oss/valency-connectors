# Sign in to Valency

One sign-in connects your agent to the corpus.

1. Choose **Sign in** here, in the notification shown after install, or run **Valency: Sign in** from the Command Palette.
2. VS Code opens your browser to sign in with Valency. Complete the sign-in and return to VS Code.

VS Code stores the sign-in and refreshes it automatically from then on. The extension ships no credentials of its own; the server is hosted at `mcp.valency.io`.

To sign in again later, run **Valency: Sign in**, or manage the server from **MCP: List Servers**.

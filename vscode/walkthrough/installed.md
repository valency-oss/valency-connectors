# What just got installed

The Valency extension added the **Valency MCP server connection** to VS Code — and runs nothing on your machine. It is a pointer to the hosted server at `https://mcp.valency.io/`, which exposes the full Valency research-corpus tool surface: semantic search, author profiles, collaboration networks, publication trends, and more.

Your agent calls these tools automatically based on what you ask. All analysis runs against the hosted Valency corpus of tens of millions of research papers and preprints.

# Run your first skill

Open Chat in agent mode and try one of these prompts — the agent picks the right skill automatically:

- **"Profile Yoshua Bengio"** — researcher profile
- **"Give me a landscape of cs.LG"** — field landscape
- **"Find papers similar to arXiv 1706.03762"** — similar papers
- **"Is diffusion model research still growing?"** — publication trends
- **"Who should Yann LeCun be talking to that he isn't already?"** — fresh collaborators

Each skill orchestrates the hosted Valency tools and answers with real corpus data, including links to every paper it cites.
